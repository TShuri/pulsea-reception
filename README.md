# Ресепшен фитнес-клуба

Веб-приложение для администратора ресепшена фитнес-клуба. Позволяет искать клиентов, открывать их карточки, отмечать посещения и оформлять новые абонементы при отсутствии активного.

## Стек технологий
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Функциональность
- Список клиентов с поиском и выбором клиента по клику.
- Карточка клиента с информацией о тарифе, дате окончания абонемента и остатке занятий (для безлимитных тарифов отображается «Безлимит»).
- Проверка активности абонемента (по дате окончания и остатку занятий).
- Отметка посещения при активном абонементе: списание одного занятия (для тарифов с лимитом) и добавление сегодняшней даты в историю посещений.
- История посещений, отсортированная по убыванию даты (новые сверху).
- Продажа абонемента при отсутствии активного: выбор тарифа и оформление с сегодняшнего дня на срок выбранного тарифа.

## Запуск проекта локально

Установите зависимости:

npm install

Запустите проект в режиме разработки:

npm run dev

Откройте в браузере адрес http://localhost:3000.

## Структура проекта
- src/app/page.tsx — главная страница, хранение состояния клиентов и функции обновления данных.
- src/components/Header.tsx — шапка приложения.
- src/components/ClientsList.tsx — список клиентов и поиск.
- src/components/ClientCard.tsx — карточка клиента, действия по посещениям и продаже абонементов.
- src/data/ — исходные данные клиентов и тарифов.
